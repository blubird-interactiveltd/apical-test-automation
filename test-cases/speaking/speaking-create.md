# Speaking Question Create: Test Cases

These cases cover the create form at `/master/question-management/question-creation/pte-question/create?type=speaking`
(`CreateView.vue` plus one type component per question type). They test the fields every type shares,
each of the 7 Speaking types, media upload, keyword syncing, Draft versus Publish, "Create another",
and the sample-answer dialog.

Business rules, field matrix and finding IDs (F-xx) are defined in [speaking-business-document.md](speaking-business-document.md).

**What each case checks.** A question is only created once, by `POST /api/v1/questions`. Every
create case therefore checks two things: **the payload the front-end sent**, and **the record
`GET /questions/{id}?intention=edit` returns afterwards**. A form that looks right but loses a field
in the payload would pass a UI-only check, so the UI alone is not enough.

**Global preconditions:**

- Logged in as Super Admin.
- Each case opens the form from the Speaking list's Create button (so `router.back()` has somewhere to go).
- Indexes follow the pattern `QA-AUTO-SPK-<TYPE>-<timestamp>`.
- Every question a case creates is deleted in `afterEach`.
- Media fixtures:

  | Fixture                | Content         |
  | ---------------------- | --------------- |
  | `speaking-short.mp3`   | ≈5 s            |
  | `speaking-lecture.mp3` | ≈60 s           |
  | `speaking-lecture.mp4` | video           |
  | `describe-image.png`   | image           |
  | `big-audio.mp3`        | > 100 MB        |
  | `big-image.png`        | > 10 MB         |
  | `invalid.pdf`          | wrong file type |

**ID scheme:** `SPK-CRT-TC-NNN`. Per type: RA 100s, RS 200s, DI 300s, RL 400s, ASQ 500s, SGD 600s, RTAS 700s.
