# Speaking Question Edit: Test Cases

These cases cover the edit form at `/master/question-management/question-creation/pte-question/edit/:id?type=speaking`.
It is the same `CreateView.vue` as create, in edit mode. It loads the question with
`GET /api/v1/questions/{id}?intention=edit` and saves with `PUT /api/v1/questions/{id}`.

Business rules and finding IDs (F-xx) are defined in [speaking-business-document.md](speaking-business-document.md).

**Global preconditions:**

- Logged in as Super Admin with QUESTION_UPDATE.
- **Fresh question per case.** Each case creates its own question of the type under test through the API in `beforeEach`, and deletes it in `afterEach`. Recorded stage questions are never edited.
- **What each case checks.** As in create, every case checks the PUT body and the record re-read with `intention=edit`.

**ID scheme:** `SPK-EDT-TC-NNN`.
