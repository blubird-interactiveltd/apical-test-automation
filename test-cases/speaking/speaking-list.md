# Speaking Question List: Test Cases

These cases cover the Super Admin Speaking question list at
`/master/question-management/question-creation/pte-question/speaking` (`SpeakingView.vue`).
They test the page, the tab strip, the table, the filters, search, sort, pagination, and which
actions show for which permissions.

Business rules and finding IDs (F-xx) are defined in [speaking-business-document.md](speaking-business-document.md).

**Global preconditions:**

- You are logged in as Super Admin (`master` role) unless a case says otherwise.
- `.env` points at stage (`BASE_URL=https://superadmin.apical.io`, `API_URL=https://api.apical.io`).
- **UI cases run against a recorded list response.** The UI cases that count rows stub
  `GET /api/v1/questions/list` with `fixtures/api/speakingList.page{1..6}.response.json`
  (118 records, recorded 2026-10-05). Data changes on stage therefore cannot break them.
- **`live` cases call the real API and assert only on shape and relative counts.** They do not rely on today's numbers.

**ID scheme:** `SPK-LIST-TC-NNN`. A case marked **Expected to fail (F-xx)** is automated with `test.fail()`.
